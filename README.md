# Geoserver Manager

Веб-приложение для управления и сравнения двух экземпляров Geoserver. Приложение предоставляет единый интерфейс для просмотра, управления и передачи стилей, слоёв и хранилищ данных между экземплярами Geoserver через REST API.

## Возможности

- **Поддержка двух Geoserver**: Одновременная настройка и подключение к двум экземплярам Geoserver
- **Навигация по разделам**: Просмотр разделов Стили, Слои и Хранилища
- **Параллельное сравнение**: Отображение данных с обоих серверов в параллельных панелях
- **Управление выборами**: Выбор элементов с помощью флачков с визуальной обратной связью
- **Операции со стилями**:
  - Просмотр детальной информации о стилях через REST API
  - Скачивание стилей в формате ZIP (SLD-файл)
  - Копирование стилей между серверами
  - Удаление стилей
- **Операции со слоями**:
  - Просмотр списка слоёв
  - Удаление слоёв
- **Операции с хранилищами**:
  - Просмотр хранилищ данных
  - Удаление хранилищ
- **Панель статуса**: Отображение количества выбранных/всего элементов для обоих серверов в реальном времени

### Управление состоянием

Приложение использует **Zustand** для управления состоянием. Хранилище (`geoserverStore.ts`) управляет:

- **Конфигурация серверов**: URL, имя пользователя и пароль для обоих экземпляров Geoserver
- **Текущий раздел**: Активный раздел (стили, слои, хранилища)
- **Данные серверов**: Данные, полученные от обоих Geoserver
- **Состояние выбора**: Выбранные элементы на каждой панели
- **Состояния загрузки/ошибки**: Управление состоянием UI
- **Состояние диалогов**: Видимость диалога информации и содержимое

### Поток данных

```
Действие пользователя → Действия Store → API Сервис → Geoserver REST → Ответ → Обновление UI
```

1. Пользователь настраивает подключения к Geoserver (URL, учётные данные)
2. Пользователь выбирает раздел (Стили/Слои/Хранилища)
3. Приложение параллельно получает данные с обоих Geoserver через REST API
4. Данные отображаются в двухпанельном макете с флачками
5. Пользователь выбирает элементы и выполняет действия (Инфо, Загрузить, Скопировать, Удалить)
6. Действия выполняются через REST API Geoserver
7. Результаты отображаются в UI

## Интеграция с Geoserver

### Настройка Geoserver

Приложение подключается к экземплярам Geoserver через REST API. Настройте параметры подключения в UI приложения:

1. **URL сервера**: Базовый URL вашего Geoserver (например, `http://localhost:8080/geoserver`)
2. **Имя пользователя**: Имя пользователя Geoserver (по умолчанию: `admin`)
3. **Пароль**: Пароль Geoserver (по умолчанию: `geoserver`)

### Используемые эндпоинты REST API

Приложение использует следующие эндпоинты REST API Geoserver:

#### Стили (Styles)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/geoserver/rest/styles.json` | Получить список всех стилей |
| GET | `/geoserver/rest/styles/{name}.json` | Получить метаданные стиля |
| GET | `/geoserver/rest/styles/{name}.sld` | Получить содержимое SLD |
| GET | `/geoserver/rest/styles/{name}.zip` | Скачать стиль в ZIP |
| POST | `/geoserver/rest/styles` | Создать/загрузить стиль |
| DELETE | `/geoserver/rest/styles/{name}` | Удалить стиль |

#### Слои (Layers)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/geoserver/rest/layers.json` | Получить список всех слоёв |
| GET | `/geoserver/rest/layers/{name}.json` | Получить метаданные слоя |
| DELETE | `/geoserver/rest/layers/{name}` | Удалить слой |

#### Хранилища (Stores)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/geoserver/rest/workspaces.json` | Получить список рабочих областей |
| GET | `/geoserver/rest/workspaces/{ws}/datastores.json` | Получить список хранилищ |
| DELETE | `/geoserver/rest/workspaces/{ws}/datastores/{store}` | Удалить хранилище |

### Настройка CORS

Если ваш Geoserver размещён на другом origin, чем приложение, может потребоваться настройка CORS на Geoserver:

1. Добавьте CORS фильтр в `web.xml`:

```xml
<filter>
    <filter-name>CorsFilter</filter-name>
    <filter-class>org.apache.catalina.filters.CorsFilter</filter-class>
    <init-param>
        <param-name>cors.allowed.origins</param-name>
        <param-value>http://localhost:5173</param-value>
    </init-param>
    <init-param>
        <param-name>cors.allowed.methods</param-name>
        <param-value>GET,POST,DELETE,PUT,OPTIONS</param-value>
    </init-param>
</filter>
<filter-mapping>
    <filter-name>CorsFilter</filter-name>
    <url-pattern>/*</url-pattern>
</filter-mapping>
```

### Аутентификация

Приложение использует HTTP Basic Authentication для запросов к API Geoserver. Учётные данные кодируются в Base64 и отправляются с каждым запросом.

## Руководство по использованию

### 1. Настройка подключений

Введите данные подключения для обоих экземпляров Geoserver в панелях конфигурации.

### 2. Выбор раздела

Выберите раздел из выпадающего списка:
- **Стили**: Управление определениями SLD стилей
- **Слои**: Управление картами слоями
- **Хранилища**: Управление хранилищами данных

### 3. Загрузка данных

Нажмите кнопку «Загрузить» для получения данных с обоих Geoserver.

### 4. Выбор элементов

Используйте флачки для выбора элементов на любой панели.

### 5. Выполнение действий

Используйте кнопки действий:
- **Инфо**: Просмотр детальной информации о выбранном стиле
- **Загрузить**: Скачивание ZIP-архива с SLD-файлом выбранного стиля
- **Скопировать**: Копирование выбранных стилей с одного сервера на другой
- **Удалить**: Удаление выбранных элементов с сервера

### 6. Мониторинг статуса

Панель статуса внизу показывает количество выбранных элементов против общего количества для каждого сервера.

## Решение проблем

### Проблемы с подключением

- Проверьте, что URL Geoserver правильный и доступен
- Убедитесь, что REST API Geoserver включён
- Проверьте правильность учётных данных
- Проверьте настройку CORS, если работаете на разных origin

### Проблемы с загрузкой

- Проверьте сетевое подключение к экземплярам Geoserver
- Проверьте консоль браузера на наличие сообщений об ошибках
- Убедитесь, что версия Geoserver 2.x (совместимая с REST API)

### Проблемы с CORS

Если вы видите ошибки CORS:
- Настройте CORS фильтр на сервере Geoserver
- Или используйте прокси в `vite.config.ts`
